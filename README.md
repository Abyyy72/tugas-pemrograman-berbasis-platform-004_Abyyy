# Tugas Pemrograman Berbasis Platform 004

Repository praktikum Pemrograman Berbasis Platform.

## Struktur Repository

- `backend/` — layanan backend dan API
- `web/` — aplikasi web
- `mobile/` — aplikasi mobile Flutter
- `docs/` — proposal, biodata, dan dokumentasi proyek

## Pertemuan 1

Fondasi repository disiapkan sesuai modul praktikum: monorepo, dokumentasi proposal, dan biodata anggota.

## Catatan

File rahasia seperti `.env`, token, password, dan credential tidak boleh di-commit.
